# QuestWeek — GitHub Pages version

This is the installable iPhone web-app version of QuestWeek.

## Included
- Daily timeline
- PPL + Upper/Lower schedule
- Core workouts of about 60 minutes and optional extras on flexible days
- 40-minute commute to gym
- Shower/change at gym
- 10–15-minute trip from gym to school
- School start at 08:15
- Japanese class Monday 17:15–19:05
- Work Tuesday and Wednesday 16:00–20:00
- Badminton, boxing, Ironman base and calisthenics
- Two 20-minute chess sessions
- Study, programming, online-income and weekly planning
- 05:30 wake / 21:30 bedtime
- Water, meditation and stretching
- Scaling XP, levels, streak multiplier, achievements and Life Quests
- Offline support and local storage
- No gym-set/reps tracker

## Publish with GitHub Pages
1. Make this repository public.
2. Open repository Settings → Pages.
3. Select “Deploy from a branch”.
4. Choose `main` and `/root`, then Save.
5. Open the Pages URL in Safari.
6. Tap Share → Add to Home Screen.

Your app data stays in the browser storage on your iPhone.
